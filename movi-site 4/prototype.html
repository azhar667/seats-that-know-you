Two-person test checklist

Try each setup with the camera running:

  1. Two enrolled people — each screen should show the correct name.
  2. One enrolled person + one stranger — name on one screen, “Welcome” on the other.
  3. Two strangers — “Welcome” on both screens.
  4. Swap seats — each person’s screen should change sides with their position.

The prototype processes at most two faces. A third face is ignored.

Setup and offline use

Run it: put this file in a folder, open a terminal there, run python3 -m http.server 8000, then open http://localhost:8000/seats-that-know-you-camera.html. Camera access needs localhost or https.

First run: the face tools and models (about 12 MB) download once from a CDN, then your browser caches them.

Fully offline: create a vendor folder next to this file with face-api.js (the dist file of the @vladmandic/face-api package) and a model subfolder holding the ssd_mobilenetv1, face_landmark_68 and face_recognition model files (.json and .bin). The page tries this folder first.

Private: camera frames are processed in the page and are never uploaded. This page makes no network requests except to fetch the tools above.
