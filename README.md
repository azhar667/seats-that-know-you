# Seats That Know You — Interactive Presentation

Open `index.html` in a modern browser (Chrome or Safari recommended).

## Navigation
- Use the bottom arrows or keyboard ← / →.
- Page 3: select a node to inspect its role in the system.
- Page 4 introduces the connected platform. Pages 7–12 reuse one evolving layout for Allocate, Analyze, Monitor, Optimize, Ask and the integrated Experience.

## Editing
1. Click **Edit presentation**.
2. Click outlined text and edit it directly.
3. Click **Save changes** to save in the current browser.
4. Export or import a JSON file to move your text edits between browsers.

This version supports local editing and JSON backup. It is not yet synchronised between teammates. Shared editing can be connected after confirming the existing Supabase project and editor-key configuration.

## References
- Page 3's connected-source → central system → outputs composition is reinterpreted from Telemyr's Data Analytics diagram.
- The continuous platform-flow pattern across pages 4 and 7–12 is inspired by the interaction structure of North.cloud's “The Platform” section. North's cloud-finance features are not copied; the functions are mapped to this project's passenger experience: Allocate, Analyze, Monitor, Optimize and Ask, followed by the integrated Experience.
