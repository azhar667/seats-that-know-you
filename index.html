ONE CABIN · FIVE CONNECTED FUNCTIONS
One system. Five functions.

Inspired by the way North presents one platform through connected capabilities, this diagram translates that structure into the passenger experience. Pages 7–12 keep the same layout while each function becomes active.

  • Allocate → connect each person to a seat zone
  • Analyze → interpret identity, occupancy and state
  • Monitor → notice changes and potential risks
  • Optimize → adjust only the zone that needs it
  • Ask → make cabin information accessible in natural language

APPLICATION

The experience begins before the ride.

Set up once.
Passengers can enrol a face profile with consent. The vehicle verifies the profile when they enter, then loads the choices associated with that person. A guest can continue without creating a profile.
